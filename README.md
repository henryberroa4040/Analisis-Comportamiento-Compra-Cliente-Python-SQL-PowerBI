## 📌 Descripción

Análisis del comportamiento de compra de **3,900 transacciones**, con el objetivo de identificar patrones de gasto, productos, descuentos, suscripciones y segmentos de clientes.

## 🔄 Flujo del proyecto

🐍 **Python** → 🗄️ **SQL Server** → 📊 **Power BI**

### 🐍 Python

- Limpieza y transformación de datos.
- Tratamiento de valores faltantes.
- Creación de grupos de edad y frecuencia de compra.
- Carga de los datos procesados a SQL Server.

### 🗄️ SQL Server

Análisis de:

- Ingresos por género y grupo de edad.
- Productos mejor valorados.
- Impacto de los descuentos.
- Suscriptores vs. no suscriptores.
- Segmentación de clientes.
- Productos más vendidos.

### 📊 Power BI

Dashboard interactivo para visualizar los principales resultados e insights del análisis.

## 🛠️ Tecnologías

**Python · Pandas · SQL Server · SQLAlchemy · Power BI · Git**

## 💡 Insights

- Impulsar las suscripciones mediante beneficios exclusivos.
- Implementar estrategias de fidelización.
- Evaluar el impacto de los descuentos.
- Potenciar productos mejor valorados y vendidos.
- Dirigir campañas hacia los segmentos de mayor valor.
